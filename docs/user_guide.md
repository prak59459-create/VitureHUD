# HUD Navigator 使い方ガイド

## 1. インストール

### A. Swift Playgrounds（iPad・何度でも試せる）
1. GitHub の [Releases](https://github.com/prak59459-create/VitureHUD/releases) → 「最新ビルド」から **HUDNavigator.swiftpm.zip** をダウンロード
2. ファイル App で zip をタップして展開
3. `HUDNavigator.swiftpm` をタップ → Swift Playgrounds で開く → ▶︎（実行）
- 初回は権限（カメラ・位置・マイクなど）のダイアログが出ます
- Playgrounds 内ではグラスへの表示が **ミラー表示** になる場合があります（端末の画面がそのまま映る）
- ショートカット連携は使えません

### B. AltStore（iPad / iPhone 15・正式アプリ）
**ソースとして追加する（おすすめ）**：AltStore →「ソース（Sources）」→「＋」→
`https://github.com/prak59459-create/VitureHUD/releases/download/latest/altstore-source.json`
を追加すると、AltStore の中から「HUD Navigator」をインストールでき、新しいビルドが出ると「更新」が表示されます
（ウィジェット付きの版は `…/altstore-source-widgets.json`。どちらか一方だけ）。

**ファイルで入れる場合**：
1. 同じ Releases から **HUDNavigator.ipa** をダウンロード（ファイルに保存）
2. AltStore → マイApp → 左上の「＋」→ HUDNavigator.ipa を選ぶ
3. 署名は7日で切れるので、AltStore で更新してください（Windows の AltServer と同じ Wi-Fi）
- グラスに HUD、端末に操作画面を出す **独立表示** を試みます
- ショートカット（Siri）連携と URL での操作（`hudnavigator://…`）が使えます
- **HUDNavigator-widgets.ipa** はホーム画面・ロック画面のウィジェットとコントロールセンターのボタン付きです（AltStore の無料アカウントでは App ID を2つ使います。7日で10個まで）

## 2. 基本の使い方

| やりたいこと | 操作 |
|------------|------|
| HUD を表示 | ホーム →「HUD を表示」（グラス接続時は自動） |
| 背景を切り替え | HUD 全画面で **2回タップ**／ホームのボタン／「黒背景にして」「カメラにして」 |
| プリセット切り替え | HUD 全画面で **左右スワイプ**／ホーム・HUD タブのボタン |
| 音声で操作 | 右下のマイクボタン／HUD 全画面で **長押し** |
| HUD を閉じる | HUD 全画面で **下にスワイプ** |
| パネルの編集 | HUD タブ → パネルをタップで選択・ドラッグで移動・右下の丸でサイズ変更・長押しで複数選択 |
| 表示位置の調整 | 設定 → 表示位置・大きさ（視野の端が見えにくいときに全体を縮める） |
| 目的地を決める | ナビ → 検索・カテゴリ・地図をタップ／「東京駅までナビして」 |
| デモ案内 | ナビ → … →「デモ案内（皇居外苑）」（GPS がなくても動作確認できる） |

### ワーク（机での作業・勉強・発表）
「ワーク」タブで操作した内容が、そのままグラスの HUD に出ます。上のカードで机向けのシーン（デスクワーク・集中・ブラウザ・発表・料理）に切り替えられます。

| 項目 | できること |
|------|-----------|
| 集中 | 集中タイマー（25 分集中 → 5 分休憩、4 回ごとに長い休憩。時間は変えられる）・タイマー・ストップウォッチ。終わると HUD・音・声・通知で知らせる |
| やること | 追加・完了・削除。HUD には「まだ」のものから並ぶ |
| メモ | いくつでも書ける。選んでいるメモが HUD に出る |
| ブラウザ | グラスにウェブページを映す。**端末の画面がトラックパッド**になり、なぞるとカーソルが動き、たたくと押せる。文字は端末のキーボードで入れて「送る」。白いページは自動で暗くする |
| 台本 | 読みたい文章を入れて再生すると、今読む行が大きく出て少しずつ送られる（速さは変えられる） |
| 予定 | iOS の「カレンダー」の今日・明日の予定（IPA 版のみ・許可が必要）。世界時計の都市もここで選ぶ |

各項目の「HUD に表示」を押すと、今のシーンにそのパネルを出したり隠したりできます。

**iPhone ではタブが 5 つ**（ホーム・ワーク・HUD・ナビ・設定）です。ビジョンとアシスタントはホームのタイルから開きます（右下のマイクを長押ししてもアシスタントが開きます）。iPad はすべてのタブが並びます。

### 音声コマンドの例
- 「集中を始めて」「集中を終了」「休憩をスキップ」「5分タイマー」「3分半測って」「タイマーを止めて」「ストップウォッチをスタート」
- 「やることに牛乳を買うを追加」「次のタスク完了」「メモ、14時に電話」「128かける3は？」
- 「猫の動画をウェブで検索」「ブラウザで example.com を開いて」「下にスクロール」「前のページに戻って」「台本を再生」
- 「デスクワークモードにして」「集中モードにして」「発表モードにして」「運動モードにして」
- 「黒背景にして」「カメラにして」
- 「徒歩ナビモードにして」「ミニマルモードにして」「サイバーパンクテーマにして」
- 「東京駅までナビして」「ナビを終了して」「近くのコンビニを探して」
- 「地図を大きくして」「地図を3Dにして」
- 「速度を表示して」「時計を消して」
- 「音声案内をオフにして」「物体認識をオンにして」
- 「今何時？」「あと何分？」「バッテリーは？」「今日の天気は？」
- 「HUD を開始して」「HUD を編集」「パネルを並べて」
- 「HUD を暗くして」「まぶしい」「文字を大きくして」「HUD を小さくして」「HUD を左に動かして」

定型コマンド以外の質問は、設定 → AIアシスタント でクラウドAI（APIキー）を設定・同意した場合のみ AI が答えます。「AI にアプリを操作してもらう」をオンにすると、「暗い所でも見やすくして」のような依頼も、AI が操作の一覧から選んで実行します（最大4つ）。

### iPad のキーボード
⌘U：HUD を表示・閉じる／⌘B：背景を切り替え／⌘→・⌘←：プリセット／⌘K：話しかける／⌘R：案内をもう一度／⌘T：集中タイマー／⌘L：ブラウザ／⌘1〜5：タブ

## 2-2. 追加機能の設定
| 機能 | 場所 | メモ |
|------|------|------|
| Google Maps（検索・経路・乗り換え案内・評価・営業時間） | 設定 → Google Maps | Google Cloud で APIキーを作成（Places API (New)・Routes API を有効化、請求先の登録が必要・無料枠あり）→ 保存 → 送信に同意 |
| 心拍計 | 設定 → 心拍計（Bluetooth） | 標準の心拍サービスに対応した胸ベルトなど。「心拍計を探す」→ タップで接続（次回から自動） |
| HUD の明るさ・夜の減光・3D・空間固定 | 設定 → 外部ディスプレイ | 3D はグラスを 3D モードに。空間固定は AirPods（Pro など）が必要 |
| 白線・標識（実験） | ビジョン → 路面の線・標識 | 見落とし・誤認識があります |
| 外部カメラ | ビジョン → カメラ | iPad の USB-C カメラ |
| 提案 | 設定 → 提案 | 雨・電池・休憩などを HUD とホームで提案 |
| テンプレート | HUD タブ → テキストパネル | 例：`{time} 電池{battery} 心拍{hr} {steps}歩` |
| 物体認識（内蔵モデル 80 種類） | ビジョン → 物体検出モデル | 黒背景（グラスで透明）のままでも認識します。初回はモデルの準備に数十秒かかります |
| 距離・障害物 | ビジョン → 距離・3D | iPhone 15 は 2 つのカメラ、A16 iPad は AI で推定。端末を少し下に向けて地面が映ると正確になります |
| 3D スキャン | ビジョン → 3D スキャン／「3D スキャンを開いて」 | ゆっくり部屋を見回すと三角形のメッシュ（Quest 風の線）になります。同じ所を何度か映すと埋まります。タップで距離。「書き出し」→ OBJ（三角形）・PLY |
| 頭の動き | 設定 → 頭の動き | AirPods・Bluetooth センサー・VITURE 公式アダプター（公開 API）・前面カメラ・端末から選ぶ。空間固定・うなずき等の操作・チラ見モード |

### VITURE の 3DoF（頭の向き）について
設定 → 頭の動き →「VITURE の 3DoF を使うには」に案内があります。
- VITURE の公式の説明では、グラスを **iPhone・iPad に直接つないだ場合、頭の向きは使えません**（iOS がアプリに USB 機器の直接操作を許可しないため。このアプリでも実機で確認済み）。公式 SDK に iOS 版はありません。
- **グラス側に空間固定の機能がある機種**（VITURE Beast など）は、アプリなしでグラスが固定します。その場合はアプリの「HUD を空間に固定」はオフに。
- **公式の USB-C XR 充電アダプター**を使うと、公式アプリ SpaceWalker では 3DoF が使えます。このアプリは「VITURE 公式アダプター（公開 API）」を選ぶと、アダプターが iOS の公開されている機能（アクセサリー通信・MIDI・オーディオ・コントローラー・外付けカメラ・有線ネットワーク）でどう見えるかを一覧にし、頭の向きのデータが届けば使います。**機器には何も送らず、非公開の機能も使いません。** VITURE は通信方法を公開していないため、見えても読めない場合があります。そのときは「結果をコピー」の内容を Issue で知らせてください。
- 確実なのは、**Bluetooth の動きセンサーをつるに付ける**方法と **AirPods** です。

## 3. グラスで見やすくするコツ
- **黒は透明**に見えます。暗い色・半透明の背景はほとんど見えません
- 設定 → 詳細 → **視認性テスト** で、読める最小文字サイズと色を確かめ、設定 → 表示位置・大きさ → 最小文字サイズ に反映
- 歩行中は画面の **15〜20% 以下**、中央を空ける配置に（HUD タブの「視界のチェック」に表示）
- 端末が熱くなると、自動で省電力（カメラ・推論の頻度を下げる）になります

## 4. 安全について
- **自動車・自転車の運転中には使わないでください**（速い速度が続くと HUD を自動で最小化します）
- 物体認識・危険検知は **実験的な補助機能** で、安全装置ではありません
- 距離・到着時刻は目安です

## 5. データ
- 履歴の保存は初期設定でオフ。設定 → 履歴・分析 で ON
- 端末間の **自動同期**：両方の端末で 設定 → データ・同期 →「同期フォルダを選ぶ」→ iCloud Drive の同じフォルダ（例：HUD Navigator）を選ぶ
- 手動の同期：設定 → データ・同期 → 書き出し → 「ファイルに保存」で iCloud Drive → 別端末で読み込み
- 訪問した場所・利用状況：設定 → 履歴・分析（端末内のみ）
- 通信の記録：設定 → プライバシー・通信ログ
- すべて削除：設定 → プライバシー → すべてのデータを削除

## 6. 実機テストと不具合の報告
1. 設定 → 実機テストモード で各項目を「OK / NG」にし、メモを書く
2. 「計測を記録」をオンにして使うと、fps・温度・電池・GPS 精度を10秒ごとに記録
3. 「結果を書き出す」→ GitHub の Issue に添付
