# 実機テスト チェックリスト

アプリの **設定 → 実機テストモード** に同じ項目があります（結果を JSON で書き出せます）。
「環境」列：PG = Swift Playgrounds（iPad・回数無制限）、IPA = AltStore の正式アプリ（週7回まで）。

**おすすめの進め方**
1. まず Swift Playgrounds（iPad）で PG の項目をできるだけ確認する（回数無制限）
2. IPA でしか確認できない項目（S0-0, S0-1 の独立表示, S0-7, P7-2）と iPhone 15 の確認を、週1〜2回の IPA でまとめて行う

## CI で確認済みの項目（実機不要）
- ロジック：レイアウト計算、ルート進捗・逸脱・到着、読み上げタイミング、危険度判定、音声コマンド解析、通知の優先度、省電力の判定、履歴集計、天気の解析、設定ファイルの互換性（Linux / `swift test`）
- iOS：アプリのビルド、AppModel のコマンド・編集・書き出し/読み込み、デモナビ（iOS シミュレータ）
- 見た目：全プリセット・全テーマ・端末サイズ・編集画面・警告表示・視認性テストの PNG（アーティファクト「hud-snapshots」）
- Swift Playgrounds 互換：`HUDNavigator.swiftpm` 単体のビルド
