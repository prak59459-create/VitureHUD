## CI で確認済みの項目（実機不要）
- ロジック：レイアウト計算、ルート進捗・逸脱・到着、読み上げタイミング、危険度判定、音声コマンド解析、通知の優先度、省電力の判定、履歴集計、天気の解析、設定ファイルの互換性（Linux / `swift test`）
- iOS：アプリのビルド、AppModel のコマンド・編集・書き出し/読み込み、デモナビ（iOS シミュレータ）
- 見た目：全プリセット・全テーマ・端末サイズ・編集画面・警告表示・視認性テストの PNG（アーティファクト「hud-snapshots」）
- Swift Playgrounds 互換：`HUDNavigator.swiftpm` 単体のビルド
