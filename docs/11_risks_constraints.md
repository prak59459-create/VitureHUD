# 11. リスク・制約一覧

## 2. 安全リスク（最優先）

| ID | リスク | 対策 |
|----|--------|------|
| S-01 | 歩行中にHUDへ注意が向き、周囲への注意が下がる | 歩行中プリセットは情報量・面積を制限（初期値：画面の15%以下）、移動中はアニメーション・点滅を抑制、重要通知以外は停止中に表示 |
| S-02 | 物体認識・危険検知を安全装置と誤解する | 「実験機能・安全装置ではない」表示を常時（Layer 4）。初回同意。警告がないことは安全を意味しないと明示 |
| S-03 | 誤検知・検知漏れ | 信頼度表示、閾値調整、検知漏れ前提の説明 |
| S-04 | 運転中の使用 | **運転中の利用を前提としない**。自動車・自転車の速度域（例：時速20km以上が続く）を検出したらHUD情報を最小化し警告。日本の道路交通法では運転中の画面注視（いわゆる「ながら運転」）が禁止されている点を利用規約・初回画面で明記 |
| S-05 | 距離・位置を断定表示して誤認させる | 推定値には「約」「目安」を付ける。取得できない値は表示しない |
| S-06 | 架空の天気・データ表示 | 取得失敗時は「取得できません」と表示。出典・更新時刻を必ず表示 |

## 3. プライバシーリスク

| ID | リスク | 対策 |
|----|--------|------|
| P-01 | 位置履歴の蓄積 | 履歴保存は既定OFF、保存期間設定、全削除 |
| P-02 | カメラ映像の外部送信 | 既定で送信しない。クラウドAIへの画像送信は機能として当面実装しない |
| P-03 | クラウドAIへの個人情報送信 | 送信内容のプレビューと同意、最小限のテキストのみ、通信ログで確認可能 |
| P-04 | APIキーの漏えい | Keychain 保存、リポジトリにコミットしない、ログに出さない |
| P-05 | 公共の場でのカメラ使用（撮影されている側への配慮） | 録画・保存機能は持たない（解析のみ・フレームは即破棄）。カメラ使用中表示 |

## 4. 法務・ライセンス

| ID | 内容 | 対策 |
|----|------|------|
| L-01 | 物体検出モデルのライセンス（AGPL等） | 採用前に個別確認。AGPLモデルは原則不採用 |
| L-02 | Open-Meteo は非商用のみ無料、CC BY 4.0 | 出典表示。商用公開時は有料プランか WeatherKit |
| L-03 | Google Maps 利用規約（表示方法・キャッシュ制限など） | 採用時に規約確認 |
| L-04 | 地図データの出典表示 | MapKit の帰属表示を隠さない（HUDミニマップでも要配慮） |
| L-05 | 「VITURE」等の商標 | アプリ名・アイコンに他社商標を使わない（「VITURE対応」の表記可否は公開時に確認） |

## 5. 制約まとめ（設計に織り込むもの）

1. HUDはアプリが**前面にある間だけ**動作する（iPhoneロックで外部出力も停止）。
2. HUDは**頭に固定**（グラス表示＝顔の向きに追従）。現実の物体に重ねるAR表示は前提にしない。
3. カメラ映像の検出枠は**端末カメラ視点**であり、グラス越しの視界と一致しない。
4. 距離・衝突予測は**推定**であり、精度を保証しない。
5. 同期は Phase 6 まで**手動（ファイル）**。
