# 12. ユーザーへの確認事項

回答に応じて計画を更新します。分からない項目は「不明」で問題ありません（Phase 0 で確認します）。

| # | 質問 | 理由・影響 |
|---|------|-----------|
| Q1 | お使いの **Swift Playgrounds のバージョン**（App Store / アプリの「情報」）を教えてください。「Swift Playgrounds 6」は Swift 6 言語のことでしょうか？ | 公開情報で確認できた最新は 4.7。機能制限の前提が変わる |
| Q2 | **Mac は使えますか？ Apple Developer Program（有料）に加入済み、または加入予定ですか？** | iPhone 15 へのインストール方法が決まる（TestFlight か Xcode か）。どちらも無い場合、iPhone 15 では動かせない |
| Q3 | iPad A16 は **Wi-Fi モデルですか、Wi-Fi + Cellular モデルですか？** | Wi-Fi モデルは GPS 非搭載。ナビの検証方法が変わる |
| Q4 | VITURE の正確な型番は **VITURE Pro 2** で合っていますか？ 給電アダプタ／Dock はお持ちですか？ | 解像度・輝度・充電しながらのテスト可否 |
| Q5 | 主な利用シーンは？（例：徒歩通勤・旅行・室内作業） | 優先するプリセット・機能の順番 |
| Q6 | アプリは **自分専用** ですか？ 将来 **App Store で公開**（無料／有料）する予定はありますか？ | Open-Meteo（非商用のみ無料）、モデルライセンス、Google 規約の扱いが変わる |
| Q7 | Google Maps は必須ですか？ MapKit で不足する具体的な機能があれば教えてください | 不要なら課金・APIキー・導入リスクを避けられる |
| Q8 | クラウドAIを使う場合、**APIキーの取得（Gemini 無料枠など）と、テキスト送信** は許容できますか？ | 不可ならアシスタントは端末内のルールベースのみ |
| Q9 | 表示言語は日本語のみでよいですか？ | 文字列カタログの設計 |
| Q10 | Phase 0 のスパイクを先に実施してから Phase 1 に入る進め方でよいですか？ | 計画書 §17 の順序どおりですが、最初のコード（検証用）を書く前に承認を得たい |
