# 頭の向きセンサー（ハードウェア）

VITURE 本体のセンサーは iOS アプリから公式には読めないため、グラスに小さなセンサーを付けて頭の向きを取れるようにしています。

## A. 市販品（おすすめ・プログラム不要）
**WitMotion の Bluetooth 5.0 センサー**（WT901BLECL など）。両面テープでグラスのつるに付けます。
アプリの 設定 → 頭の動き →「Bluetooth の動きセンサー」→「センサーを探す」で接続し、必要なら「50Hz」で出力を速くします。
通信仕様：通知 FFE4（サービス FFE5）、データ `0x55 0x61` + 加速度・角速度・角度（各 16 ビット）。

## B. 自作（ESP32）
`HUDIMUSensor/HUDIMUSensor.ino` を M5StickC Plus2 などに書き込みます（Arduino IDE・M5Unified ライブラリ）。
「HUD-IMU」という名前で現れ、向き（度）と加速度（G）を約 50 回/秒送ります。

| 項目 | 値 |
|------|----|
| サービス UUID | 4855444E-4156-4900-8000-494D55000000 |
| 特性（通知） | 4855444E-4156-4900-8000-494D55000001 |
| データ | float32 × 3（yaw・pitch・roll、度）＋任意で float32 × 3（加速度 G）、リトルエンディアン |
| 向き | 右を向く／上を向く／右に傾ける＝プラス |

向きが逆の場合は、アプリの「左右を反転」などで合わせてください。
